# Security

Please report a security problem **privately**, not in a public issue or pull request.

Use GitHub's private reporting: the **Security** tab of this repository, then **Report a
vulnerability**. We'll answer there.

In scope: this extension, and the CHOOM.GG stream relay and card image hosts it talks to (anything
that would let someone see a deck they shouldn't, impersonate a streamer's share, or disrupt the
relay). Please don't run load tests or denial-of-service tests against the relay.
